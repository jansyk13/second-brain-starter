# Associative Memory

_Short sticky facts with soft links, consolidation, and recall across sessions — not a second wiki._

## What it is

In this stack, Hindsight holds prefs, decisions, corrections, and other residue that should follow the agent. Recall can surface related memories without an explicit `[[wikilink]]`. That is a different job from [[Compiled Knowledge]].

## Why it matters

The wiki will never grow inceptions or latent associations the way a memory system does. Keep research in the vault; keep sticky agent facts in Hindsight; keep the current agenda in `hot.md`.

## Mechanics

Retain short durable facts; recall on session start / topic switch; do not paste full wiki pages into retain. If memory and a wiki page disagree, cite both and file a contradiction on the wiki page.
